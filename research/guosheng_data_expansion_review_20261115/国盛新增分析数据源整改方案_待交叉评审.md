# 国盛新增分析数据源整改方案

待交叉评审，2026年11月15日。适用对象为本地国盛六周期多资产ETF月频版本。本文规定拟补充的数据、研究问题和验证顺序，供网页端复核及后续模型执行。新增接口账户覆盖、完整历史版本和策略收益增量均待验证。

## 决策摘要

**建议补充一个独立的经济与资产环境分析层。第一批补PPI价格结构和官方PMI需求分项，同时展开已有信用数据。工业产出、消费、财政及黄金外部环境按用途逐步补齐。只有前两项进入首轮预测增量实验。**

需要区分三个决策。数据能解释原信号，足以进入分析记录。数据能在原信号之外区分未来资产收益，才值得设计交易规则。交易规则扣费后提供稳定、可接受的收益风险交换，才有理由进入候选交易版本。这三种结论分别记录。

工程顺序与研究优先级有所不同。最先完成原有数据的状态与时间核验，再展开已具备的居民和企业中长期贷款。真正新增的经济维度，优先研究工业品价格。PMI新订单与库存紧随其后，接入轻便，但与原PMI有较多重叠。工业产出和消费主要提供外部核验。黄金的海外利率和汇率用于资产解释，可同步准备来源，交易实验排在后面。

目前没有证据可以估计新增这些数据会增加几个百分点年化。本轮读取了网页端最新答复、相关本地代码与既有结果，并核对官方方法和接口文档，没有运行新增数据回测。网页端原文另存于本目录，便于逐条交叉评审。

## 对网页端意见的逐项判断

| 网页端建议 | 本轮判断 | 需要补全的条件 |
|---|---|---|
| 优先增加PPI、核心CPI，区分价格压力 | 同意，PPI作为首个新增研究维度 | 加工品涨价也可能来自成本传导。总PPI、加工PPI、核心CPI不能自动合成为“需求强弱”分数 |
| 看PMI新订单、生产、库存 | 同意，适合作为第一批分析数据 | 原材料库存与产成品库存不同。扩散指数之差不等于实物库存销售比。新增分项不重复增加独立票数 |
| 信用与财政拆开看 | 同意，信用展开先做，财政随后补 | 企业贷款包含再融资等用途，借款主体也不能简单等同私人部门。政府融资、预算支出、最终需求分开解释 |
| 黄金补美国实际利率、人民币汇率 | 同意，资产解释价值较高 | 用人民币黄金进行归因时，要分开美元金价、汇率和境内外价差，不能重复计入汇率收益 |
| 市场走势用于核查宏观判断 | 同意作为诊断，交易规则另审 | 宏观与价格冲突可能是市场提前反映，也可能是阶段噪声。价格过滤一旦影响持仓，需要独立验证 |
| 先观察错误换仓是否集中于冲突 | 需要扩大样本定义 | 同时记录正确换仓、错误换仓及没有换篮的月份，避免只寻找亏损案例的共同特征 |
| 首轮最多三个改版方向 | 建议收窄到两个预测实验 | 先做价格结构、PMI需求结构。市场过滤留待后续，避免同时搜索阈值、资产、窗口和频率 |

原作者已讨论相关替代数据。2024模型原稿P.13–14认为工业增加值等与PMI相关性较高，作者测试的“PMI加需求”没有明显增益。P.15明确规定没有匹配六阶段时延续前一阶段。因此，补数据需要针对具体遗漏提出假设，既不能把原作者的选择当成最终真理，也不能忽略其已有反证。原稿文本位于 `guosheng_original_audit_20261113\tmp\pdfs\2024.txt`。

两项本地事实约束了方案。

- 已有154个完整调仓区间中，居民和企业对总信用方向的贡献有73期相反。此前诊断中，相反组的原选篮表现没有更差，现有结果不支持“信用分歧就减仓”。这只是既有历史诊断，没有证明分歧有正向预测能力。
- 2026年7月1日读取的信用总方向、居民贡献和企业贡献均为负。模型仍沿用阶段2，原因是当时三维方向没有映射到六阶段。单纯拆开贷款数据，无法自动修复这次持仓。应单独标记“当前三维方向”和“延续的阶段”，避免误把阶段2描述为所有进攻条件仍成立。

这些数字来自 `guosheng_macro_auxiliary_20261115\decision_date_credit.csv` 和 `guosheng_timing_attribution_20261115\收益来源与择时审查.md`。阶段延续问题与新增指标问题分别记录，研究中避免同时修改两者。

## 数据补充范围与优先级

| 顺序及用途 | 最小数据集合 | 解决的问题 | 本轮建议的使用权限 |
|---|---|---|---|
| 0 原输入可信度 | 七类政策公告状态、DR007、三项PMI、两类中长期贷款的来源和可用日期 | 数据没变、尚未发布、抓取失败、统计改制能否区分 | 原策略输入核验及异常说明 |
| 1 现有信用展开 | 居民和企业中长期贷款对原信用脉冲的贡献 | 总量改善是否由单一部门推动，是否接近零线 | 解释与数据质量诊断 |
| 2 价格结构 | 总PPI及加工、采掘、原材料、生活资料同比和环比 | 工业价格压力及其来源 | 解释，首轮主实验H1 |
| 3 PMI结构 | 新订单、生产、产成品库存，附购进价格与出厂价格 | 原增长信号是否得到需求分项支持 | 解释，首轮主实验H2仅使用新订单 |
| 4 产出与消费 | 官方工业增加值可比价同比、社零官方同比 | 调查指标是否得到后续实际统计支持 | 外部核验，首轮不增加交易投票 |
| 5 价格补充 | 核心CPI，必要时总CPI作为背景 | 工业成本是否向居民端扩散 | 解释，核心CPI缺历史时不阻断H1 |
| 6 黄金及长债环境 | 美国10年实际收益率、匹配时点的USD/CNY即期，国内10年与30年同定义国债收益率 | 国内宏观之外的资产定价变化 | 资产归因、冲突提示，后续独立研究 |
| 7 信用财政扩展 | 政府债融资、一般公共预算支出、政府性基金支出 | 融资增加与支出落地是否一致 | 事件背景与机制核验 |

顺序代表维护和研究优先级。首批完成价格及PMI字段后即可开展有限诊断，不必等待所有外围数据齐备。

PPI提供工业价格维度，但不能单独识别供给冲击与需求冲击。PMI新订单与生产已经参与总指数，加上它们会重用调查信息。官方编制方法还明确了配送时间为逆向分项，供给受阻可能影响总指数解释。以上因素支持保留分项记录，并要求在原信号条件下验证增量。[PMI编制方法](https://www.stats.gov.cn/zs/tjws/zytjzbqs/cgzlzs/202501/t20250121_1958396.html)

工业增加值覆盖工业生产，社零主要覆盖商品零售及餐饮。两者能核验不同侧面，不能充当整个经济的唯一“真实状态”，尤其不能用制造业产出直接判定原非制造业PMI错误。[社零统计说明](https://www.stats.gov.cn/sj/zxfb/202603/t20260316_1962786.html)

GDP、工业利润、M1与M2、新闻情绪、数十项高频产业指标暂列后续候选。是否加入，需先说明其能解决哪个未被本轮覆盖的问题，再核验历史口径和维护成本。

### 获取路径

### 最小记录格式

| 字段组 | 至少记录的内容 |
|---|---|
| 身份与定义 | 指标名、统计期、单位、是否季调、分类或基期版本 |
| 原始数值 | 原表数值、修订版本号或版本时间、原公告位置 |
| 时点 | `released_at`公开时点、`first_received_at`实际首次接收时点、历史取证日期 |
| 可用依据 | 原公告、当时快照、保守日期推定、仅当前历史表，明确区分 |
| 质量 | 已核验、尚未到期、已确认未变、延期、失败、无权限、来源冲突、口径变化 |

保留原始表及少量清晰的版本记录即可，沿用现有CSV、Parquet和运行清单，首轮无需引入新的因子平台、模型搜索系统或常驻服务。

### 历史与实际接收采用不同证据

历史公共信息回放使用能够证明当时已发布的版本。今天补录的接收日期不能冒充2014年的接收日期，也不能把全部历史数据都推迟到今天才可用。历史中没有接收记录时，标为“公开信息回放”，另做固定延迟压力。

实际跟踪使用 `max(公开时点, 首次成功接收时点)`。如果发布了新值而采集失败，可以展示旧值及旧统计期，状态为“已过发布期限、尚未更新”。未知值不能填零，也不能当作经济没有变化。

研究样本分为三层。有原始发布值和时点的记录可进入严格时点回放。只有日期的原公告按当日结束确认，进入其后的决策截点。只有今天历史表而没有当时版本的记录可做探索。统一延迟一天不能修复后来修订的数值。

计算滚动特征时，所有历史滞后项也要使用决策时点已经可得的版本。后来的修订可以在它发布后影响后续判断，但不能覆盖此前保存的决策。若只能恢复首发快照而缺历次修订，要说明采用“首发序列近似”，与完整当时信息集分开。原始记录和最终特征各自记录时点证据等级。特征按全部输入中最弱的证据定级，列明降级月份。当前PPI有原公告、三个月前PPI只有现值表时，整项H1观察不能标为严格时点数据，H2滚动窗口同理。

### 决策时钟

当前基线按月初目标日读取前一交易日的 `known` 日期，属于日级归档。新增分析快照建议将这个已知日的截点显式写为北京时间日终，与日级公共信息回放对应。它不证明旧账本已经具备分钟级发布时间认证。

- 月初快照只使用该 `known` 日结束前可得的资料。休市期间后来发布的数据等到下一个允许的截点，不能悄悄提前原基线。
- 日常分析记录可在每次正式发布后更新，月频交易实验仍按冻结的月初目标日运行。提频收益与新增信息收益分别比较。
- 中债日终曲线约北京时间17:30发布，适合次日使用，不能参加当天15:00决定。[中债说明](https://yield.chinabond.com.cn/cbweb-pbc-web/pbc/more?locale=cn_zh)
- 美国市场按当地日期、实际可用时间、夏令时和节假日转换。中国周二早晨不能使用美国周二收盘值。日级美国数据只有日期且缺历史发布时间证据时，主方案采用保守的完整美国日结束后再留一完整中国交易日缓冲。美国日按`America/New_York`定义，转换至`Asia/Shanghai`，中国交易日采用ETF交易日历，不能固定加12或13小时。另列常规可用时点对照，不挑较好结果。

发布计划是预期，原公告才是已发布证据。月初常同时面对本月PMI、上月或更早信用及价格统计，快照逐项列出统计期和数据年龄，避免拼成一个虚构的“同步经济状态”。[统计局发布日程](https://www.stats.gov.cn/sj/fbrc/bnxxfb/)

### 特殊口径

- **春节及修订**。工业、社零的1—2月合并值保持一个联合观察，不拆成两个伪月值。官方季调环比可能修订。PMI已季调，本轮没有依据声称它必然每月修订，实际检查版本差异。[季调说明](https://www.stats.gov.cn/hd/cjwtjd/202302/t20230207_1902267.html) · [社零发布表及修订说明](https://www.stats.gov.cn/sj/zxfb/202603/t20260316_1962786.html)
- **价格基期**。保留官方同比、环比和当时分类，记录2026年启用2025基期等断点。不要把今天的权重回套历史，累计同比也不等于月度价格变化。[基期轮换说明](https://www.stats.gov.cn/xxgk/jd/sjjd2020/202602/t20260211_1962589.html)
- **财政**。仅在同定义、同修订口径下，用累计额之差构造单月支出。跨年和1—2月不能直接这样处理，前月累计被修订时要单列差额。政府性基金与一般公共预算分别解释，不相加成未经核对的财政强弱分数。
- **汇率**。中间价与即期收盘属于不同序列。中间价可作政策背景，人民币黄金归因采用时间匹配的即期价格。若美元金价单位为美元每金衡盎司，则境内人民币每克价格约为 `美元金价 × 人民币每美元汇率 ÷ 31.1034768 × (1＋境内外基差)`。ETF净值相对境内现货的费用与跟踪差异、交易价格相对净值的溢折价分别核算。ETF已有的汇率收益不重复加入账户。[官方汇率交易时间说明](https://app.www.gov.cn/govdata/gov/202301/01/495736/article.html)

## 分阶段验证方案

### 第一阶段 形成解释快照

以原月频基线每一个目标日为观察点，保留所有成功、失败和未换篮月份。快照包含下表内容，持续更新仅产生分析记录。

| 模块 | 输出 |
|---|---|
| 原策略 | 当前货币、信用、增长方向，实际采用阶段，直接匹配或沿用，沿用起点与持续时间，原目标资产和权重 |
| 信用 | 居民贡献、企业贡献、合计，是否相反，原总方向到零线的距离 |
| 价格 | PPI总量和主要分项的水平及变化，核心CPI如已可得，可能的成本或需求解释 |
| PMI需求 | 新订单、生产、产成品库存的原值及固定变换结果，原增长信号与订单信号是否冲突 |
| 实体确认 | 最新工业增加值、社零与其统计期，随后公布的同参考期结果单列为复盘标签 |
| 资产环境 | 实际利率、汇率、国内长端收益率及既有价格走势，记录冲突而不合成总分 |
| 数据状态 | 每条数据的来源、公开与接收时间、统计期、版本及未知项 |

信用展开继续采用已经实现的可加总方法。记居民与企业新增中长期贷款的12个月合计为H和E，总和为T，则居民对总信用同比的贡献为 `(H_t−H_{t−12})/T_{t−12}`，企业同理。两项各减去三个月前的值，之和等于原信用方向输入。分母必须有效且为正，异常时标记未知。单独计算各部门同比会改变定义，不能与这套贡献口径混合。

解释允许并列多个机制。例如订单和价格同时上升支持需求改善，也可能伴随供给约束。没有已校准的概率模型时，不输出“经济复苏概率80%”之类数字。相关指标不按数量叠加可信度。

### 第二阶段 冻结两个主假设

冻结时间为交叉评审结束、后续模型开始计算之前。已有历史全部属于已见研究材料。每项主假设固定一个输入定义、一个主结果变量及一个方向，记录反向或无效结果。其他字段先保留解释用途。

两项主诊断沿用已有归因口径，资产收益从目标日收盘计算至下一目标日收盘，末端未完成区间剔除。使用原研究相同的复权、分红及代理收益身份，输入截点仍在目标日前。这个口径不包含目标日开盘到收盘的损益，实际成交收益及交易成本在后续账户回放中另算。自然月收益不与目标区间收益混用。

**H1 工业价格是否提供资产相对收益的增量信息。**

- 输入固定为当时已发布的加工工业PPI同比相对三个月前的变化，单位为百分点。总PPI、采掘、原材料和核心CPI仅用于解释背景。本定义沿用已有三个月方向尺度，属于待评审选择，不代表三个月最优。
- 主结果为下一完整月频目标区间内，有色资产收益减长债资产收益。主假设方向为输入上升对应相对收益上升。成本传导与需求不足可能反驳这个方向，结果不成立时不翻转符号另选赢家。
- 依次报告仅按原阶段、加入当前三信号与沿用状态、再加入截至已知日21交易日有色减长债收益的固定对照。控制价格可能吸收宏观传导的一部分，各层结果一起保留。主条件增量结论依据最后一层，不能挑最显著的一层。只有控制后仍稳定存在的部分，才能支持它提供这些已有信息之外的增量。
- 主要估计使用全部可核验月份。相同阶段可能沿用自不同的当前三维方向，因此实际阶段与当前货币、信用、增长方向分别控制。阶段4单列机制展示，不在其中搜索价格阈值或再切需求、财政、利率子组。
- 失败情形包括收益只集中在一段事件，控制原阶段后消失，只有价格发布前的收益显著，或效果仅来自当前修订历史值。

**H2 新订单是否能辨认原增长信号的薄弱月份。**

- 对官方制造业新订单应用与原增长分量相同的变换。先求12个月均值，再求相对12个月前的变化率，最后取该变化率相对三个月前的变化方向。完整暖机至少需要27个月原始数据，实际按首个有效值核验。
- 主口径采用原三PMI信号所使用的同一参考月份，并在同一已知日截点取值。原增长方向为正的月份，检验新订单方向为负时，原选篮减未选篮的下一完整区间等权收益是否更低。该收益是诊断量，尚未计入真实交易成本。
- 比较时控制原阶段、当前三方向、直接匹配或沿用，以及原三PMI各自的方向分量。官方制造业总PMI的同变换结果必须进入实质对照，不能仅展示。原增长多数票向上时，制造业原分量可能已经为负，此时订单偏弱可能只是重复已知信息。缺少订单正负对照、共同支持或增量变异时，明确报告无法识别。
- 另外固定报告一个及时性对照，按各指标实际可得的最新参考月份取值。官方新订单可能比原三PMI合成更早更新，两者差异可能提供有价值的及时性，但不能全归给需求结构。同步参考月口径为主，最新可得口径为辅助，不按收益择优，也不增加第三个主假设。首轮不再测试“订单超过50”“订单减库存”或一批更快窗口。
- 产成品库存用于事件解释。库存增加可能是主动备货，也可能是销售受阻，单个扩散指数不判定原因。制造业订单也不能直接替代原非制造业与民间PMI三者的全部信息。
- 失败情形包括区分仅在单一阶段成立，匹配阶段后消失，或者提前性来自未来发布的数据。

统计上，两项研究都在比较新增X对指定原信息Z之外的条件收益解释，核心对象可写为 `E[r_next | Z,X] − E[r_next | Z]`。相关关系不能自动解释为因果关系。预注册使用实际阶段的分类主效应、当前方向的固定−1/0/+1编码和沿用标记的加性对照。H2再加入三PMI分量同一编码，主结果中控制截至已知日21交易日原选篮减未选篮收益。首轮不在方向编码与连续脉冲间择优，也不拟合全交互。数学上冗余的控制列按截距、阶段、当前货币信用增长、沿用、三PMI分量、价格的固定顺序保留线性独立列并记录，新增解释变量最后检验。控制后新增变量没有变异，或缺乏共同支持时，结论为“在该控制集合下未识别”，不改模型追求显著。

以上估计属于带线性加性假设的历史诊断，不能声称完全控制所有宏观原始信息或识别了因果收益。若后续把拟合系数用于交易，系数只能用每个决策日前已完成的收益标签估计，再逐期向前预测。全样本系数不能回填为可交易历史信号。

### 第三阶段 验证经济解释与预测分别成立到什么程度

对PMI及实际产出、消费，另做一个经济核验表。把决策时已知的调查判断，与随后首次公布的对应统计期产出或消费方向比较。后者是结果标签，不能倒灌为输入。分别报告工业和消费，春节联合统计期保持联合。

这张表回答经济判断是否得到后续统计支持。H1和H2回答下个持有区间资产收益是否得到区分。即使前一张表改善，后一张表不改善，也可以长期保留辅助分析用途。

黄金模块先检查收益解释。人民币金价的对数变化近似分解为美元金价变化、人民币每美元汇率变化和境内外价差变化。美国实际收益率使用当时可得的变动量，先检验不同阶段关系是否稳定。海外实际利率具有解释机制，但历史关系存在阶段变化，不能直接设成黄金买卖开关。[芝加哥联储研究](https://www.chicagofed.org/publications/chicago-fed-letter/2021/464)

### 第四阶段 稳定性及多重研究约束

1. **同一日期同一数据身份比较。** 基线、辅助变量和V12使用共同起止及同一收益版本。新增源历史较短，就缩短三者共同样本并公布损失的月份，不能只展示新增方案可用的好时期。
2. **样本按决策周期计数。** 当前基线有154个完整调仓区间，其中阶段4为21个。已归档的近期真实报价账户在阶段4只有3个完整区间。它们不是数千次独立宏观试验。每项还要报告连续阶段事件数、冲突月份数、实际可能改变的目标次数。
3. **历史分段提前列明。** 固定展示2014—2019、2020—2022、2023—2025、2026截至数据终点，以及逐年结果。有跨段的持有区间注明归属规则。所有这些都属于历史稳定性诊断，不能重新标为未见样本外。
4. **依赖与不确定性。** 使用预先固定的12个月时间块重采样报告效应范围，同时做逐个连续冲突事件留一分析。样本过少时不依赖渐近显著性。若给出两项主假设的p值，报告对两项主比较的校正口径。辅助分段和敏感性不冒充额外独立验证。
5. **避免收益集中掩盖问题。** 单列最大贡献事件，报告移除该事件后结论如何变化。该操作只检查结论集中度，不把合法择时收益从主成绩中扣除。
6. **有限参数邻域。** 主定义完成后，H1三个月差分只检查2和4个月邻值，H2只检查其末端方向比较的2和4个月，其他处理不变。它们属于事先登记的脆弱性检查，全部报告，不选择最高收益版本。新增、放弃和失败的定义都进入尝试清单。
7. **时点与版本压力。** 对两项新增输入统一延迟1及3个中国交易日，另列首发证据与当前历史表的差异。基础三信号保持原对照口径，避免一次修改多个部件。原输入若发现确定错误，先形成纠错版，再在纠错后的相同基线上比较。
8. **未来记录。** 交叉评审完成后冻结定义和开始时间，新到的发布与决策逐次留档。观察数量要以独立事件和结果区间计，固定经过几个月不自动构成验证通过。

H1与H2合计为两个研究主张，四个邻域检查不成为四条新候选策略。若研究过程中增加市场趋势开关、财政打分、通胀阈值或替代资产，必须在记录中明示新增假设，重新区分探索与确认结果。

## 纳入交易规则的条件

**本次方案的直接产物是辅助数据和固定诊断。交易映射需要后续独立决策。** 当前证据尚不足以预设“PPI上涨就取消长债”或“订单弱就卖创业板”，提前写入这类动作会引入未经证明的资产选择。

| 验收层级 | 可以得出的结论 | 需要的证据 |
|---|---|---|
| 数据可用 | 可以进入分析记录 | 定义清楚，时点与版本可追溯，未知状态明确，维护成本可接受 |
| 解释有用 | 可以帮助理解原判断和失败原因 | 当时可得，能区分备选解释，能记录反例，避免重复计票 |
| 预测有增量 | 值得提出一个交易改版 | H1或H2效应具有一定跨事件一致性，原信号与价格对照后仍有实质信息，有限邻域不呈孤立尖峰 |
| 交易改版有价值 | 可以成为前瞻跟踪候选 | 固定动作、固定资产和参数的扣费回放，风险收益交换符合用户偏好，改善来源可解释 |

达到第三层后，后续模型先交付一张候选规则卡，写明触发、有效期、唯一动作、退出、缺失处理、调仓频率及新增自由度。先冻结规则卡，再运行对应账户。原月频国盛是主要增量基准，V12是用户的机会成本基准。仅超过V12而低于原国盛，不能证明新增数据带来价值。

沿用的主比较条件为50万元、原月初目标、63日风险估计、单边9bp滑点另加1.5bp佣金及最低5元。固定同一资产代理、真实ETF准入、现金与成交逻辑。另列20bp滑点压力。原月频与“月初配权加换篮加调”分别作为清楚命名的版本，避免混表。

报告净年化、波动、最大回撤、下行风险、换手、总费用、最长相对落后期、受影响目标次数，并逐次解释新增规则改变了什么。保持用户偏好，适度风险增加可以接受，收益只小幅增加而风险大幅恶化时不升级。不能只按回撤下降或夏普上升挑方案，也不以删除原有合法择时收益制造公平。

本轮不擅自设定一个未获用户确认的风险厌恶系数或“最优综合分”。候选应展示净收益增量与波动、回撤增量的对应关系，列出在更高成本和不同历史条件下是否仍有优势。既有多次研究及原作者筛选过程不能从统计区间中消失，历史改善仍需冻结后的新证据支持。

## 交付物与评审问题

后续分析测试模型按以下顺序交付。

1. `数据源覆盖表`，逐指标列字段、权限、起点、结束点、首发证据覆盖、版本差异和缺口。正文说明哪些仅取得最新历史表。
2. `月度辅助判断表`，按原目标日列当前方向、实际阶段、沿用状态、信用展开、价格与需求分项、公开时点和未知项。先确认增加分析层没有改变基线目标及账本。
3. `冻结研究协议`，记录H1、H2定义、分段、主终点、邻域、成本、全部预定比较与冻结时间。
4. `增量信息检验`，报告效应、条件对照、事件分母、分段、时点及版本压力，保留失败结果和所有尝试。
5. `下一步判断`，逐项给出保留解释用途、继续积累证据、值得设计交易规则或停止研究。若提出交易规则，另附规则卡，账户结果作为下一阶段产物。

网页端优先评审以下问题。

- PPI加工同比三个月变化是否是足够清楚的首个价格假设。若建议替代定义，请在看新增回测之前给出唯一主定义及机制。
- H2采用原增长变换尺度，是否足以避免把“更快反应”误当作“需求结构更好”。原三PMI与制造业分项的范围差异是否已充分处理。
- 阶段沿用与输入缺失的标记，是否足以防止把已有信号失配误诊为缺少指标。
- 原始发布时间、实际接收时间、修订版本和跨市场时区规则有无漏洞。
- 两项主假设及少量邻域是否已足够，是否存在未登记的候选选择空间。
- 验收是否既尊重用户收益优先，也充分记录提高收益所付出的风险和成本。

可以接受交叉评审后的结论是“数据值得补，调仓规则暂时没有足够改进证据”。这意味着分析层完成了职责，交易版本保留原有可解释性。

# 网页端复核证据包

打开《国盛六周期综合分析.md》看结论和来源。把《发给网页端Pro的提示词.txt》复制到对话中。

- daily_nav.csv 提供 12 条逐日账户净值，第一行是每组起始基准净值。运行 python recalculate.py 可重算年化、波动、最大回撤、累计收益。真实报价模拟另按 2026-06-30 收盘净值作基准，复核 7 月以来表现。
- quote_ledger 包含月频、阶段变化加调及 V12 的近期模拟账本、目标与成交明细。
- evidence 按原研究目录分组，含输入边界、审计、归因、频率与成本汇总、部分本地源码和验证记录。汇总 CSV 的比例单位为小数。源码是定位证据，完整执行依赖未打包的本地快照及模块。
- 所有数据为研究回放。共同结束日为 2026-11-12，收益情景的特殊共同截止为 2026-11-04。两个聊天复用的账本只算一份证据。

# 国盛六周期多资产 ETF 复现研究

截至 **2026-11-12**，按公开资料重建的月频版在五个同期起点都跑赢 V12。2016 年起的含代理回放净年化 **22.50%**，最大回撤 **18.64%**。研报发布后的六只真实 ETF 模拟净年化 **19.99%**，最大回撤 **8.91%**，覆盖 **247 个交易日和 13 次目标配置**。这套规则值得继续验证，原研报的 23% 和完整模型仍待独立复现。

## 同期结果

各起点使用 100 万元独立建仓。表内依次为**净年化 / 年化波动 / 最大回撤幅度**。ETF 账本使用真实开盘价撮合，单边滑点 9bp 另加万 1.5 佣金、最低 5 元。两条策略使用同一成本和执行模型。

| 起点 | 六周期月频重建 | V12 | 数据口径 |
|---|---:|---:|---|
| 2016-01-04 | **22.50% / 12.07% / 18.64%** | 11.94% / 9.91% / 14.04% | 金额模型，含上市前代理 |
| 2020-01-02 | **22.23% / 13.45% / 18.65%** | 11.90% / 10.84% / 14.01% | 金额模型，含上市前代理 |
| 2022-01-04 | **19.93% / 12.18% / 10.58%** | 10.82% / 10.72% / 10.30% | 金额模型，含上市前代理 |
| 2025-07-01 | **39.82% / 17.95% / 8.89%** | 13.16% / 11.14% / 8.16% | 真实 ETF，含研报发布前四个月 |
| 2025-11-06 | **19.99% / 18.69% / 8.91%** | 6.26% / 12.25% / 8.22% | 真实 ETF，研报发布后 |

- 2016 年起，候选净年化高约 **10.56 个百分点**，波动高 **2.17 个百分点**，回撤深 **4.60 个百分点**。最差连续三年净年化约 **10.24%**，同期 V12 **6.38%**。最大回撤落在 2020 年 3 月，2020 年 7 月恢复。
- 发表后，候选净年化高 **13.73 个百分点**，波动高 **6.44 个百分点**，最大回撤深 **0.68 个百分点**。该窗口最后一次最大回撤出现在 2026-11-06，截止时尚未完全恢复。
- 发表后只做同六资产的月度全池风险平价，净年化 **3.35%**、最大回撤 **4.54%**。六周期带来的收益提升同时伴随集中度和换手上升。候选该段年化双边换手 **10.90 倍**，V12 **2.00 倍**。
- 单边滑点提高至 **20bp**，发表后六周期月频版净年化 **18.59%**，V12 **6.03%**。固定 V12 的 9bp 基线，候选发表后年化优势在其自身单边滑点 **120–121bp** 间归零。这是模型的成本敏感性，尚无该组合的实测成交滑点。
- 同期三个预先冻结的轮动版本均有留档。仅 DR007 的月频敏感性为 **23.07%**（2016 起）和 **19.99%**（发表后）。加做阶段变化次日调仓为 **21.20%** 和 **32.53%**，发表后该版最大回撤 **10.57%**。两者都保留为诊断，结论采用主月频版。

## 公开规则和实现边界

国盛用货币、信用、增长三个方向区分六个阶段。按 2024 年研究的说明，三方向落在其余两种组合时保留上一阶段。2026 年作者继续展示了 2025 年六周期方案的配置表。高波版各阶段对以下标的做风险平价，不设置低波版的目标波动上限。［[国盛 2024 因子方法，第 5–6 页](https://aigc.idigital.com.cn/djyanbao/%E3%80%90%E5%9B%BD%E7%9B%9B%E8%AF%81%E5%88%B8%E3%80%912024%E5%B9%B4%E5%BA%A6%E9%87%91%E8%9E%8D%E5%B7%A5%E7%A8%8B%E4%B8%AD%E6%9C%9F%E7%AD%96%E7%95%A5%E5%B1%95%E6%9C%9B-2024-07-14.pdf) · [2025 报告](https://www.sdyanbao.com/detail/933398) · [作者后续说明，图表 1 和 5](https://finance.sina.com.cn/wm/2026-05-06/doc-inhwxhnn8400327.shtml)］

## 回报集中度和核验

- 发表后创业板约贡献 **12.92 万元**毛盈利，占净利润约 **63%**。有色期货约贡献 **6.25 万元**。按已成交账本删去贡献最高的 1% 交易日，净年化降到 **10.91%**；去掉创业板预算并留现金重跑为 **11.15%**。两项结果都仍高于该段 V12 的 **6.26%**。
- 2016 年起同样的两项诊断分别为 **14.48%** 和 **15.86%**，均低于主回放 **22.50%**，高于同期 V12 **11.94%**。
- 六只 ETF 在发表后对照区间各 **248 根**开收盘价与 QMT 8002 对齐。35 个账本通过成交先后、资金、费用和收益恒等式检查。另核实 159915 于 2021-02-08 因持有人大会停牌，估值保留前收盘，协方差剔除停牌日和跨日的复牌回报。［[159915 停牌公告](https://pdf.dfcfw.com/pdf/H2_AN202102081459963456_1.pdf?1612777675000.pdf=)］
